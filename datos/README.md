# Fuente de datos

La demostración documentada empleó el archivo **sintético** `desvios_presupuestarios_ficticios_n8n.xlsx`, hoja `Datos_n8n`, con 495 registros de 16 bancas. Este ZIP no incluye el archivo Excel porque no estaba disponible como fichero verificable durante el empaquetado. La ingesta permite cargarlo mediante el formulario de n8n; tras reiniciar n8n se debe cargar otra vez.

**Nunca subir datos del banco ni una copia que contenga información confidencial.**
